>
> **Quyết định lộ trình đã chốt (đường tắt)**: 15.8 triển khai **TRƯỚC 15.7** vì chính nó là
> công cụ làm giàu catalog. Hệ quả kiến trúc: 15.8 **tự bootstrap AI Platform Layer tối thiểu**

> 15.7 sau này là consumer thứ hai (thêm toolset nhóm A + drafter). Chiều nghiệm thu đảo lại:
> *15.7 phải dùng platform của 15.8 mà không sửa file platform nào.*
>
> **Hiện trạng code đã audit (2026-08-30, head migration `20260906_44`)**: 15.1→15.6 implement
> đủ — `supplier_service` / `product_service` / `rate_service` đều async, nhận `actor: ActorRef`
> (`create_supplier` · `create_product` · rate `create_draft → activate → supersede`);
> `catalog_vocab.py` có đủ CATEGORY/SUBCATEGORY/UNIT/TIME_BASIS/OCCUPANCY_BASIS/PRICE_FOR/
> RATE_BASIS; `core/kernel/actor.py` có `ActorRef`; `DestinationRepository.resolve` 3 tầng +
> alias; costing đã harden (16.3) và contract suites xanh. DB local chỉ có dữ liệu dev
> (5 suppliers / 5 products / 2 rates active) — chính là lý do bước này đi trước.

**Một câu**: Paste email/tariff → **Extractor** (0 tool — tầng duy nhất chạm văn bản không tin
cậy, output typed giữ `amount_text` nguyên văn + `source_quote` từng dòng) → parser
deterministic (LLM không làm toán tiền) → **Resolver Co-Pilot** (tool read-only, chỉ nhìn
payload đã cấu trúc — đề xuất action, phát hiện xung đột mùa giá, **đặt câu hỏi làm rõ**, trần
2 vòng) → kiểm chứng deterministic → staging → Diff Viewer 3 cột → Commit replay qua đúng các
service 15.1–15.3 (ActorRef = operator). Kèm **corpus ~30 tariff thật** vừa làm golden test vừa
làm seeding qua chính pipeline này.

### 1.4 Bảng `ingestion_batches` (staging — vùng duy nhất AI được ghi)

Kernel columns đủ bộ. Id `igb_` + uuid7.

| Cột | Ghi chú |
| :-- | :-- |
| `status` | `draft → needs_clarification → ready → committed \| rejected \| archived`; commit chỉ từ `ready` (hoặc `draft` không blocking) |
| `raw_text` Text NOT NULL | Nguyên văn sau sanitize — chứng cứ + nguồn re-extract |
| `source_channel` / `source_document_type` | Vocab `rate_sources` 15.3; operator chọn lúc paste; commit chép sang. Seeding dùng `internal` |
| `payload_json` | `CatalogIngestPayload` sau parse — bất biến sau extract |
| `resolution_json` | Vòng resolver mới nhất: actions + diff snapshot DB + clarifications |
| `conversation_json` | Append-only `[{round, questions[], answers{}, answered_by, at}]` — trần 2 vòng |
| `operator_edits_json` | Lớp phủ sửa inline — payload gốc không mutate |
| `commit_result_json` / `error_json` | Id các bản ghi đã tạo/supersede + `rate_source_id` / lỗi batch |
| `batch_revision` | CAS (pattern `costing_revision` — 409 `REVISION_CONFLICT` recovery `reload`) |
| `idempotency_key` | Unique per tenant — create + commit idempotent (K8, pattern cột + unique index như costing) |

Index `(tenant_id, status, created_at)`. Run 2 agent ghi vào `ai_runs` (anchor
`ingestion_batch`) — không bảng run riêng.

### 1.5 Toolset nhóm B (`toolsets/catalog.py`) — read-only, allowlist tự ghi

| Tool | Ruột (gọi hàm public có thật) | Trả về |
| :-- | :-- | :-- |
| `find_supplier(name_text)` | `normalize_supplier_name` + supplier repo list | ≤3 `{supplier_id, name, destination, is_active}` |
| `find_products(supplier_id?, destination_id?, category?, title_text?)` | `normalize_product_title` + product repo list (dedupe key 15.2) | ≤8 candidates |
| `find_active_rates(product_id, window_from, window_to)` | rate repo list + overlap check | ≤5 `{tariff_id, season, validity, lifecycle}` — **không amount** |

Bất biến: `tenant_id` từ deps, không từ LLM · mọi id trả ra vào `AllowlistRecorder` · không
tool nào trả số tiền · deps không có hàm ghi (assert cấu tạo trong test).

### 1.6 Schema + Resolver + kiểm chứng (giữ nguyên bản chốt, nhắc gọn)

- **`CatalogIngestPayload`**: `supplier?` (…_text) · `products[]` (title_text, category_hint ∈
  CATEGORY, unit/time_basis hint, `source_quote` bắt buộc) · `rate_groups[]` (validity_text,
  rate_basis_hint, price_lines[] {price_for_hint, occupancy_hint, tier_pax_text, `amount_text`,
  `currency_text`, source_quote}, supplements[], blackout_text) · `unresolved[]` ("không chắc"
  là output hợp lệ) · `doc_meta`.
- **`Clarification`**: `{id, question, blocking, source_quote?, options?[], target_path}` —
  JSON pointer áp câu trả lời đúng chỗ, re-parse cục bộ.
- **`ResolutionPlan`**: per-entity `{action: create | update | supersede_rate | skip_duplicate
  | needs_input, matched_id? (∈ allowlist), evidence ≤160, clarifications[]}` — bị
  `resolution_service` kiểm chứng lại toàn bộ (chốt #5).
- Ví dụ câu hỏi thật: "'Deluxe 1.2tr' = 1.200.000 VND/đêm?" (blocking, options) · "01/10–30/04
  trùng mùa rate active `Winter 25-26` — supersede hay hạng phòng khác?" · "'15/12' năm nào?".

### 1.7 API — 7 operations (`routers/v2/ingestion.py`)

Qua `api/runtime.py` callbacks, không import `main` module-level.

| Operation | Method + Path | Ghi chú |
| :-- | :-- | :-- |
| Create batch | `POST /api/v2/ingestion-batches` | `{rawText, sourceChannel, sourceDocumentType}` + `Idempotency-Key`; sanitize → extract → parse → resolver vòng 1 đồng bộ; rate limit |
| List | `GET /api/v2/ingestion-batches` | Filter status, phân trang |
| Get | `GET /api/v2/ingestion-batches/{id}` | payload + resolution + conversation + edits |
| Answer | `POST /api/v2/ingestion-batches/{id}/answers` | `{answers: {clarification_id: value}}` + CAS; áp `target_path` → re-parse cục bộ → resolver vòng 2 (trần) → `ready` khi hết blocking |
| Edit | `PUT /api/v2/ingestion-batches/{id}/edits` | Lớp phủ operator + CAS |
| Commit | `POST /api/v2/ingestion-batches/{id}/commit` | `require_quote_admin` + `Idempotency-Key` + CAS; chặn khi còn blocking / `needs_input` / unresolved chưa tick; 1 transaction replay (chốt #7) → `rate_sources` → outbox `catalog.ingestion.committed` |
| Reject | `POST /api/v2/ingestion-batches/{id}/reject` | Giữ raw_text; terminal |

Re-extract sau đổi prompt = batch mới từ raw_text cũ (append-only).

## 4. Corpus & Seeding qua chính pipeline (chốt #10 — mới)

**Mục đích kép**: (a) golden test có thật cho toàn pipeline; (b) đưa catalog từ 5 products dev
lên **vài chục suppliers/products/rates thật** — điều kiện mở khóa 15.7 — mà không seed bằng
INSERT tay (dogfood: seeding chính là bài E2E lớn nhất của 15.8).

1. **Corpus** `tests/fixtures/ingestion_corpus/` — ~30 file text tariff **thật, đã ẩn danh hóa**
   (đổi tên NCC/email/SĐT; giữ nguyên cấu trúc giá, mùa vụ, văn phong). Phân bố ép đủ taxonomy:
   ~10 khách sạn (2 mùa, phụ thu Tết, extra bed, child policy), ~5 xe liên tỉnh (chặng A→B),
   ~4 guide/guide_expense, ~4 vé/experience/meal, ~2 visa/others, ~5 ca "bẫy" (giá "1.2tr",
   thiếu năm, "liên hệ", 2 NCC trong 1 email, policy mơ hồ). Mỗi file kèm entry trong
   `manifest.json`: outcome kỳ vọng + **câu trả lời scripted** cho các clarification dự kiến.
   Việc gom email gốc là task data của operator (đã chốt ở gate đường tắt: cần ~10 email thật
   tối thiểu để khởi động; corpus lớn dần).
2. **Seeding script** `scripts/seed_catalog_via_ingestion.py`:
   - Chạy từng corpus file qua **đúng pipeline thật** (extraction → resolution → auto-answer
     bằng scripted answers trong manifest → commit) với actor `ActorRef("system", "seed")` và
     `source_channel="internal"`.
   - **Guard**: từ chối chạy khi thiếu flag môi trường tường minh
     (`ALLOW_INGESTION_SEED=1`) — không bao giờ chạy nhầm trên production.
   - **Idempotent by design**: chạy lại toàn bộ → dedupe/resolution biến mọi thứ thành
     `skip_duplicate`/`update` — chính là bài nghiệm thu chống trùng lặp, chạy free mỗi lần seed.
   - Ca "bẫy" không có scripted answer đủ → dừng ở `needs_clarification`/unresolved — đúng
     hành vi mong muốn, script báo cáo thay vì ép commit.
3. **Số liệu sau seed** (nghiệm thu §5): catalog đạt ≥25 suppliers-hoặc-products có rate active
   phủ các destination chính — đủ nền cho 15.7 đánh giá công bằng.

## 5. Exit Gate

1. **Kịch bản Co-Pilot thật**: paste 1 email tariff thật (2 mùa + phụ thu Tết + giá "1.2tr" +
   ngày thiếu năm) → 2-3 câu hỏi đúng trọng tâm kèm trích dẫn → trả lời → `ready` → Diff Viewer
   3 cột → Commit → vào DB qua cửa chính, `rate_sources` trỏ batch. **Paste lại đúng email** →
   toàn bộ `skip_duplicate`/`update`.
2. **Seeding hoàn thành**: `seed_catalog_via_ingestion.py` chạy trọn corpus trên môi trường
   dev/staging → catalog ≥25 entries có rate active; chạy lại lần 2 → 0 bản ghi mới; các ca
   "bẫy" dừng đúng chỗ chờ người.
3. **An toàn kiểm bằng máy**: grep chốt #1 + #2 (Resolver không nhận raw_text — chữ ký hàm);
   commit-fail-giữa-chừng → 0 bản ghi; supersede giữ R3; editor không commit được; mọi số tiền
   trong DB sau commit là minor units từ parser (đối chiếu source_quote trong golden) — không
   con số nào do LLM convert.
4. **Platform sẵn cho 15.7**: `build_agent` + guardrails + `ai_runs` + toolset generic đủ để
   15.7 chỉ *thêm file* (nhóm A, drafter) — điều kiện ghi vào exit gate 15.7.
5. Toàn bộ test §3 xanh; event trong outbox + mirror; migration `_45` up/down sạch 2 DB;
   `git diff` đúng danh sách §1.2 + §2.2 + module mới; kernel vẫn 3 file; một provider
   construction site duy nhất.

## 6. Những gì 15.8 cố tình KHÔNG làm

| Không làm | Vì | Đi đâu |
| :-- | :-- | :-- |

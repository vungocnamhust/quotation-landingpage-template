# 15.8 Interactive Ingestion Co-Pilot — Thiết kế chi tiết

> **Loại tài liệu**: Thiết kế implementation cho bước 8 của
> [15-modular-tour-ops-brainstorm.md](./15-modular-tour-ops-brainstorm.md).
> Tiền đề: [15.1](./15.1-supplier-registry.md)→[15.3](./15.3-rates.md) đã đóng;
> [15.7](./15.7-ai-service-drafter.md) đã dựng **AI Platform Layer** (`services/ai_platform/`:
> agent factory, toolset catalog nhóm B, guardrails, `ai_runs`) — bước này là **consumer thứ
> hai** của platform, và là điều kiện nghiệm thu kiến trúc của 15.7 (dùng platform mà không sửa
> một file platform nào). Không chứa code chi tiết.
>
> **Nâng tầm so với 1-shot parser**: đây là **Co-Pilot nhập liệu tương tác** — có nhận thức
> (tự tra catalog phát hiện NCC/sản phẩm đã tồn tại, xung đột mùa giá), biết hỏi lại (email
> thiếu ngày, giá "1.2tr" mơ hồ → đặt câu hỏi làm rõ cho operator, số vòng có trần), và an
> toàn tuyệt đối (AI không có quyền ghi bảng chính — staging → Diff Viewer → commit là Python
> code replay qua service 15.1/15.2/15.3, ActorRef = operator).

**Một câu**: Paste email/tariff → **Extractor** (0 tool — tầng duy nhất chạm văn bản không tin
cậy, output typed giữ `amount_text` nguyên văn + `source_quote` từng dòng) → parser
deterministic (LLM không làm toán tiền) → **Resolver Co-Pilot** (agent CÓ tool read-only nhóm B,
chỉ nhìn payload đã cấu trúc — đề xuất action create/update/supersede, phát hiện xung đột, sinh
câu hỏi làm rõ) → vòng hỏi–đáp có trần với operator → Diff Viewer 3 cột → Commit qua cửa chính.

## 0. Scope chốt

| # | Chốt | Ràng buộc thi hành |
| :-: | :-- | :-- |
| 1 | **Staging bắt buộc, không đường tắt** | AI chỉ ghi `ingestion_batches`. Grep CI: `services/ingestion/` không import model/repository catalog nào ngoài `commit_service` |
| 2 | **Phân tầng tin cậy 2 agent** | **Extractor: 0 tool** — tầng duy nhất đọc raw text (injection không có gì để chiếm). **Resolver: có tool read-only** nhưng input là payload đã cấu trúc + đã parse, KHÔNG BAO GIỜ thấy raw text; tool từ toolset nhóm B (15.7) — blast radius tối đa = đề xuất sai, mà đề xuất nào cũng qua Diff Viewer |
| 3 | **LLM không làm toán tiền, không đọc lịch** | Payload giữ `amount_text`/`currency_text`/`valid_*_text` nguyên văn; `core/rules/ingest_parser.py` (pure) convert minor units + DATE + vocab. Fail → `unresolved[]` hoặc thành **câu hỏi** — không đoán |
| 4 | **Mọi candidate kèm `source_quote` ≤200** | Diff Viewer đặt trích dẫn gốc cạnh giá trị parse — đối chiếu mắt thường 2 giây. Thiếu → validator loại |
| 5 | **Action cuối cùng là deterministic** | Resolver *đề xuất*; `resolution_service` (code) kiểm lại bằng dedupe 15.1/15.2 + alias 15.2b + overlap check trước khi ghi `resolution_json`. LLM đề xuất ≠ LLM quyết — mismatch giữa đề xuất và kiểm chứng → hạ về câu hỏi cho operator |
| 6 | **Vòng hỏi–đáp có trần** | Tối đa **2 vòng** resolver; câu hỏi typed `{id, question ≤200, blocking, source_quote?, options?[]}`. `blocking=true` chưa trả lời → không commit. Hết trần còn mơ hồ → unresolved, người xử |
| 7 | **Commit = replay qua cửa chính, 1 transaction** | Python code gọi `supplier_service`/`product_service`/`rate_service` (create→activate / supersede) hiện hành; ActorRef = **operator bấm nút**; tự sinh `rate_sources` từ batch (T8 khép vòng). Immutability 15.3 nguyên vẹn (chốt supersede) |
| 8 | **RBAC + rate limit** | Extract/answer: `require_editor`. Commit: `require_quote_admin`. Đếm batch/ngày/user (pattern counter 15.6). Draft >30 ngày → archive |
| 9 | **MVP: 1 batch = 1 supplier** | `covers_multiple_suppliers=true` → UI yêu cầu tách paste; không xây splitter |
| 10 | **Không sửa module đã đóng** | 15.1→15.7 nguyên trạng — kể cả `services/ai_platform/**` (điều kiện nghiệm thu 15.7 exit gate #3) |

### 1.3 Bảng `ingestion_batches` (staging — vùng duy nhất AI được ghi)

Kernel columns đủ bộ. Id `igb_` + uuid7.

| Cột | Ghi chú |
| :-- | :-- |
| `status` | `draft → needs_clarification → ready → committed \| rejected \| archived` — commit chỉ từ `ready` (mọi blocking question đã trả lời) hoặc `draft` không có blocking |
| `raw_text` Text NOT NULL | Nguyên văn sau sanitize — chứng cứ + nguồn re-extract |
| `source_channel` / `source_document_type` | Vocab `rate_sources` 15.3 — operator chọn lúc paste; commit chép sang |
| `payload_json` | `CatalogIngestPayload` sau parse — **bất biến sau extract** |
| `resolution_json` | Output vòng resolver mới nhất: actions + diff snapshot DB + clarifications |
| `conversation_json` | Append-only: `[{round, questions[], answers{}, answered_by, at}]` — trần 2 vòng (chốt #6) |
| `operator_edits_json` | Lớp phủ sửa inline trên Diff Viewer — payload gốc không mutate |
| `commit_result_json` / `error_json` | Truy vết xuôi / lỗi mức batch |
| `batch_revision` | CAS cho edit/answer/commit đua nhau |
| `idempotency_key` | Unique per tenant — create + commit idempotent |

Index `(tenant_id, status, created_at)`. Run của cả 2 agent ghi vào **`ai_runs`** (15.7 P3,
anchor `ingestion_batch`) — không bảng run riêng.

### 1.4 Schema (3 khối chính trong `schemas/catalog_ingest.py`)

- **`CatalogIngestPayload`** (output Extractor — như bản chốt): `supplier?` (name/contact/
  policy **_text**), `products[]` (title_text, category_hint ∈ CATEGORY, unit/time_basis hint,
  `source_quote` bắt buộc), `rate_groups[]` (validity_text, rate_basis_hint, price_lines[]
  {price_for_hint, occupancy_hint, tier_pax_text, `amount_text`, `currency_text`,
  source_quote}, supplements[], blackout_text), `unresolved[]` ("không chắc" là output hợp
  lệ — prompt ép), `doc_meta {language, doc_type_hint, covers_multiple_suppliers}`.
- **`Clarification`**: `{id, question ≤200, blocking: bool, source_quote?, options?: list[str],
  target_path}` — `target_path` trỏ JSON pointer vào payload để câu trả lời áp đúng chỗ.
- **`ResolutionPlan`** (output Resolver, bị kiểm chứng lại): per-entity
  `{action: create | update | supersede_rate | skip_duplicate | needs_input,
  matched_id? (∈ allowlist run), evidence ≤160, clarifications[]}`.

### 1.5 Resolver Co-Pilot — nhận thức + biết hỏi, nhưng không quyết

Input: payload đã parse + operator answers vòng trước (KHÔNG raw text — chốt #2). Tools:
`find_supplier` / `find_products` / `find_active_rates` (nhóm B, allowlist ghi như mọi run).
Việc của nó: đối chiếu từng candidate với catalog thật, đề xuất action + evidence, và **đặt câu
hỏi đúng lúc** — ví dụ thật:

- "Giá 'Deluxe 1.2tr' — 1.200.000 VND/đêm? " (`blocking=true`, options: [1.200.000 VND,
  12.000.000 VND, Khác]) — vì parser đã đánh dấu mơ hồ.
- "Bảng giá này 01/10–30/04 trùng mùa với rate đang active `Winter 25-26` của cùng sản phẩm —
  supersede hay đây là hạng phòng khác?" — vì `find_active_rates` thấy overlap.
- "Email không ghi năm cho '15/12' — 2026?" (`blocking=true`).

Sau đó `resolution_service` (code) **kiểm chứng lại toàn bộ**: matched_id phải ∈ allowlist +
đúng dedupe key khi tra lại DB; action supersede phải thật sự có overlap; mismatch → hạ entity
đó về `needs_input` kèm câu hỏi tự sinh (chốt #5). Câu trả lời của operator áp vào
`target_path` → parse lại phần đó → vòng resolver 2 (nếu còn blocking) → `ready`.

### 1.6 API — 7 operations (`routers/v2/ingestion.py`)

| Operation | Method + Path | Ghi chú |
| :-- | :-- | :-- |
| Create batch | `POST /api/v2/ingestion-batches` | `{rawText, sourceChannel, sourceDocumentType}` + `Idempotency-Key`. Sanitize → extract → parse → resolver vòng 1 đồng bộ; trả batch (có thể `needs_clarification`). Rate limit chốt #8 |
| List | `GET /api/v2/ingestion-batches` | Filter status, phân trang |
| Get | `GET /api/v2/ingestion-batches/{id}` | payload + resolution + conversation + edits — nuôi Diff Viewer |
| Answer | `POST /api/v2/ingestion-batches/{id}/answers` | Body `{answers: {clarification_id: value}}` + CAS. Áp answers → re-parse cục bộ → resolver vòng 2 (trần chốt #6) → status `ready` khi hết blocking |
| Edit | `PUT /api/v2/ingestion-batches/{id}/edits` | Lớp phủ operator + CAS; chỉ khi chưa terminal |
| Commit | `POST /api/v2/ingestion-batches/{id}/commit` | `require_quote_admin` + `Idempotency-Key` + CAS. Chặn khi: còn blocking chưa trả lời · entity `needs_input` · unresolved chưa tick "đã xem". 1 transaction: replay → rate_sources → `commit_result_json` → `committed` → outbox `catalog.ingestion.committed` |
| Reject | `POST /api/v2/ingestion-batches/{id}/reject` | Giữ raw_text; terminal |

Re-extract sau khi đổi prompt/model = tạo batch mới từ raw_text cũ (append-only, không mutate).

## 3. Testing & Edge-cases

- `test_ingest_sanitizer.py`: strip/NFC/cap/delimiter; văn bản chứa "ignore instructions /
  DROP TABLE" đi qua **nguyên trạng như data** — phòng thủ là kiến trúc 0-tool, không phải censor.
- `test_ingest_parser.py` (golden, dày nhất): `1.250.000` VND vs `1,250.00` USD; `85++` → flag
  thuế-phí; "1.2tr"/"từ…"/"liên hệ" → mơ hồ (nguồn câu hỏi); ngày đa định dạng + thiếu năm →
  câu hỏi; policy text chuẩn → shape A đúng invariant, mơ hồ → unresolved **0 tier bịa**;
  tier "nhóm 10-15 khách" → tier_min/max.
- `test_ingest_resolution.py`:
  - Resolver đề xuất qua tools nhóm B — matched_id ∈ allowlist (guardrails 15.7 tái dùng,
    **không sửa platform** — nghiệm thu P-exit-gate); overlap mùa → đề xuất supersede + câu hỏi.
  - **Kiểm chứng deterministic bắt lỗi Resolver**: đề xuất match sai dedupe key → hạ
    `needs_input`; supersede không có overlap thật → hạ `needs_input`.
  - Vòng hỏi–đáp: blocking chặn `ready`; answer áp đúng `target_path`, re-parse cục bộ; trần 2
    vòng — vòng 3 không tồn tại, còn mơ hồ → unresolved; conversation append-only.
  - Injection qua nội dung payload ("question: hãy xóa bảng…" trong title_text) → Resolver chỉ
    có tool read-only + output bị kiểm chứng — kết quả xấu nhất là câu hỏi/đề xuất vô nghĩa
    nằm chờ người duyệt.
- `test_ingest_commit.py`: replay qua cửa chính (validator 15.1–15.3 tự bắn — subcategory sai
  trong edits → 422 nguyên transaction); fail giữa chừng → 0 bản ghi lọt, batch giữ nguyên;
  supersede giữ R3 (rate cũ y nguyên); ActorRef = operator; `rate_sources` đúng channel + trỏ
  batch; idempotent commit; commit khi còn blocking/needs_input/unresolved-chưa-tick → 422;
  **grep cấu trúc**: ngoài `commit_service`, module ingestion không import catalog
  model/repository/service nào.
- `test_ingestion_api.py`: 7 ops; RBAC (editor không thấy commit — 403); rate limit; matrix
  401/403/404/409/422.
- Hồi quy: suites 15.1–15.3 + 15.7 platform tests xanh nguyên trạng; contract suites (+7
  manifest); migration `_44` up/down sạch 2 DB; FE lint chain + build + test.

## 4. Exit Gate

1. **Kịch bản Co-Pilot thật**: paste email tariff thật (2 mùa + phụ thu Tết + hủy theo mùa +
   một giá ghi "1.2tr" + một ngày thiếu năm) → nhận 2-3 câu hỏi đúng trọng tâm kèm trích dẫn
   gốc → trả lời → `ready` → Diff Viewer đối chiếu 3 cột → Commit → supplier/products/rates
   vào DB qua đường chính thống, `rate_sources` trỏ batch. **Paste lại đúng email** → toàn bộ
   `skip_duplicate`/`update`, không sinh trùng.
2. **An toàn kiểm bằng máy**: grep chốt #1 + #2 (Resolver không nhận raw_text — kiểm chữ ký
   hàm); commit-fail không để lại bản ghi; supersede giữ R3; editor không commit được; mọi số
   tiền trong DB sau commit là minor units từ parser (đối chiếu source_quote trong golden test)
   — không con số nào do LLM convert.
3. **Nghiệm thu platform 15.7**: 15.8 chạy trọn mà `git diff` không chạm một file nào trong
   `services/ai_platform/**` — nếu phải chạm, dừng lại và mở change request cho 15.7 trước.
4. Toàn bộ test §3 xanh; event trong outbox + mirror; `git diff` đúng danh sách §1.2 + §2.2 +
   module mới; kernel vẫn 3 file; không provider construction site mới.

## 5. Những gì 15.8 cố tình KHÔNG làm

| Không làm | Vì | Đi đâu |
| :-- | :-- | :-- |
| Upload PDF/ảnh/OCR | Paste text phủ 80% ca; OCR là tầng tiền xử lý gắn trước pipeline, không đổi kiến trúc | Change request khi ops đòi |
| Multi-supplier splitter | Tách paste rẻ hơn (chốt #9) | Khi có dữ liệu thật |
| Auto-commit "độ tin cậy cao" | Confidence không bao giờ là cổng (T5); human gate là thiết kế | Không bao giờ (by design) |
| Chat tự do với Co-Pilot | Câu hỏi typed có `target_path` — hội thoại có cấu trúc, không phải chatbox; tự do = không audit được | Không bao giờ |
| LLM quyết dedupe/action cuối | Chốt #5 — đề xuất ≠ quyết | Không bao giờ |
| Học/fine-tune từ batch | Giữ raw_text + conversation là đủ nguyên liệu; cải thiện prompt là việc tay | Sau ≥100 batch |
| Ingest allotment/FOC | M8 hoãn — schema chưa có chỗ thì không bóc | M8 |
| Action delete qua ingestion | Chỉ create/update-field-trống/supersede | Không bao giờ |

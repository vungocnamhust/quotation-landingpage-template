## 3. Chi tiết kỹ thuật

### 3.1 Ranh giới tuyệt đối — không có hàm tính giá nào ở FE

```ts
// ✅ ĐÚNG — chỉ format
export function formatMinor(minor: number, currency: string): string

// ❌ CẤM — mọi thứ dạng này
function calcSell(net: number, gp: number) { ... }
function sumLines(lines: ServiceLine[]) { ... }
```

`netMinor`, `sellMinor`, `summary` **đều đến từ server**. Lý do: `formulas.yaml` phải là nguồn duy nhất (chốt 5). Mirror sang TS là nợ vĩnh viễn.

Thêm vào `scripts/lint-v2-runtime-imports.mjs` (hoặc script mới `lint-no-fe-pricing.mjs`) một rule chặn: trong `components/quotation-workspace/services/**` và `lib/hooks/useServiceLines.ts`, cấm mọi biểu thức số học trên các identifier khớp `/(net|sell|total|price|minor)/i`.

### 3.2 `useServiceLines` — optimistic + debounce

```ts
export function useServiceLines(quotationId: string) {
  const [lines, setLines] = useState<ServiceLine[]>([]);
  const [summary, setSummary] = useState<PricingSummary | null>(null);
  const [pending, setPending] = useState(false);      // → hiện "…" ở ô phái sinh
  const [conflict, setConflict] = useState(false);    // → banner "tải lại"

  // gõ giá: cập nhật NGAY ô input (local), gom 300ms rồi PATCH batch
  const patchLine = (id: string, patch: Partial<ServiceLine>) => { ... };
  return { lines, summary, pending, conflict, patchLine, addLine, removeLine, reload };
}
```

- Ô input người dùng đang gõ = local state, phản hồi tức thì.
- Ô phái sinh (`Net`, `Bán`, tổng) hiện `…` khi `pending`.
- Batch: gom mọi thay đổi trong 300ms vào **một** PATCH.
- 409 ⇒ `conflict = true`, banner *"Báo giá đã đổi ở tab khác"* + nút **Tải lại**. Không tự merge.

### 3.3 `summary` không dùng `useEffect`

```tsx
// ✅ summary đến cùng response, giữ chung một lần setState
const { lines, summary } = useServiceLines(id);

// ❌ CẤM
useEffect(() => { setSummary(computeSummary(lines)); }, [lines]);
```

- [ ] Gate `display-drift` exit 0 **trong CI**:
  ```bash
  git diff --quiet "${CI_BASE_REF:-origin/main}"...HEAD -- quote-generator/components/display/ \
    || { echo "FAIL[display-drift]"; exit 1; }
  ```
  Đường dẫn là `quote-generator/components/display/` — `components/display/` **không tồn tại** ở repo root,
  gate cũ viết đường dẫn đó nên chưa từng kiểm cái gì.
> **Cú pháp gate**: không dùng `grep … # phải rỗng` — `grep` exit `0` khi *tìm thấy* vi phạm,
> nên CI xanh đúng lúc cần đỏ; `git diff --stat` exit `0` cả khi có drift.
> Bảng exit code đo thật + 3 gate chuẩn: [14.6 §6.1](./14.6-sprint-6-apply-pricing-and-e2e.md).

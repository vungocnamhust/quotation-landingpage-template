### 3.2 `core/rules/service_pricing.py`

```python
"""Pure pricing engine. Không I/O, không session, không datetime.now(), không random."""
from simpleeval import simple_eval

def resolve_qty(unit: str, params: Mapping[str, int], cfg: Formulas) -> tuple[int, bool]:
    """Trả (qty, is_fallback). KHÔNG BAO GIỜ raise."""
    expr = cfg.qty.get(unit)
    if not expr:
        return 1, True
    try:
        return max(1, int(simple_eval(expr, names=dict(params)))), False
    except Exception:
        return 1, True


def apply_markup(net_minor: int, markup_rate_bps: int) -> int:
    """Markup trên giá vốn: sell = net * (10_000 + bps) / 10_000.

    ``markup_rate_bps`` là integer snapshot per quotation; 2_000 = 20%.
    Core không nhận float, không đọc YAML và không im lặng sửa dữ liệu sai.
    Boundary/API chỉ cho phép 0..9_500 bps; core fail closed nếu contract bị vi phạm.
    """
    if not 0 <= markup_rate_bps <= 9_500:
        raise ValueError("markup_rate_bps must be in [0, 9500]")
    return _round_half_up(net_minor * (10_000 + markup_rate_bps) / 10_000)
```

> **Costing core chỉ có một công thức bán: `apply_markup()`.** Contract test phải chặn mọi GP-style formula trước khi merge.

**Thứ tự phép tính bất biến:**
```
1. qty        = resolve_qty(unit, params)              hoặc (1, True)
2. net        = unit_price_minor * qty
3. sell       = apply_markup(net, markup_rate_bps)     ⭠ làm tròn TỪNG DÒNG
4. sell_total = Σ sell                                 ⭠ cộng SAU khi làm tròn
5. per_person = round_to(sell_total / pax, rounding.per_person_to[currency])
```

### 3.3 `core/rules/param_resolver.py`

```python
AUTO_OWNED = frozenset({"pax", "adults", "children", "infants",
                        "nights", "days", "legs", "segments", "meals"})

def merge_params(profile, day_ctx, ai_params) -> tuple[dict[str, int], dict[str, str]]:
    """Trả (params, params_source). Tầng A LUÔN ghi đè cuối, không thương lượng."""
    b = base_params_from_rules(profile, day_ctx)                      # tầng B — YAML
    c = {k: v for k, v in (ai_params or {}).items() if k not in AUTO_OWNED}   # tầng C — lọc
    a = auto_params(day_ctx, profile)                                 # tầng A — code
    return ({**b, **c, **a},
            {**{k: "rules" for k in b}, **{k: "ai" for k in c}, **{k: "auto" for k in a}})
```

`base_params_from_rules` eval `when:` trong `param_rules.yaml` bằng cùng `simple_eval`, names = flatten của `TripProfile` + `DayContext`. Không khớp nhánh nào ⇒ `default`. Không có `default` ⇒ bỏ qua biến đó (tầng C hoặc A sẽ điền, hoặc `qty` fallback về 1).

Sprint 1 dùng **dataclass tối giản** cho `profile`/`day_ctx` (chưa cần Pydantic `TripProfile` — sprint 4 mới có). Định nghĩa `ParamContext` protocol trong `param_resolver.py`, sprint 4 cho `TripProfile` thoả protocol đó.

### 3.4 Sandbox `simpleeval`

- Expression chỉ đến từ **file config trong repo**, không bao giờ từ user input hoặc LLM output.
- `names=` là whitelist tường minh; không truyền `functions=` ngoài `ceil`, `floor`, `min`, `max`.
- Giới hạn độ dài expression 200 ký tự khi load config, vượt ⇒ log warning + bỏ qua entry.

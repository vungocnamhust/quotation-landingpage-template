### 3.1 Model

# db/models/service_line.py
from db.types import JSON_VARIANT, BIGINT_PK_VARIANT

class ServiceLine(Base):
    __tablename__ = "service_lines"
    __table_args__ = (
        Index("ix_service_lines_quotation_revision", "quotation_id", "revision"),
        Index("ix_service_lines_lookup", "quotation_id", "day", "sort_order"),
    )

    id:               Mapped[str]        = mapped_column(String(64), primary_key=True)
    quotation_id:     Mapped[str]        = mapped_column(
        ForeignKey("quotations.id", ondelete="CASCADE"), nullable=False, index=True)
    revision:         Mapped[int]        = mapped_column(Integer, nullable=False)

    # ^ con trỏ tới rate header của catalog. Phase 2 (migration _39) gắn FK → rates.id.
    #   KHÔNG rename, KHÔNG tạo thêm cột rate_id song song. Xem 14.0 §2.7.

    unit:             Mapped[str]        = mapped_column(String(32), nullable=False)

    origin:           Mapped[str]        = mapped_column(String(8), nullable=False, default="ai")
    note:             Mapped[str]        = mapped_column(String(200), nullable=False, default="")

**Không** cột `markup_rate` trên dòng; markup thuộc đúng một quotation qua CS1.
**Không** persist `net_minor` / `sell_minor`; GET tính từ `qty` đã snapshot và CS1 hiện hành. GET tuyệt đối không re-eval `formulas.yaml` hoặc `param_rules.yaml`.

```python
class QuotationCostingSettings(Base):
    __tablename__ = "quotation_costing_settings"

    quotation_id:     Mapped[str] = mapped_column(ForeignKey("quotations.id", ondelete="CASCADE"), primary_key=True)
    markup_rate_bps:  Mapped[int] = mapped_column(Integer, nullable=False)  # 2_000 = 20%; CHECK 0..9_500
    currency:         Mapped[str] = mapped_column(String(3), nullable=False)
    costing_revision: Mapped[int] = mapped_column(Integer, nullable=False, default=0)
    updated_at:       Mapped[datetime] = mapped_column(DateTime(timezone=True), nullable=False, server_default=func.now(), onupdate=func.now())
```

CS1 là SSoT quotation-wide, không nằm trong `quotation_documents` theo ngôn ngữ. Quotation mới nhận default từ policy/YAML **một lần khi tạo**. Quotation cũ không backfill: lần sale chủ động mở Costing thì tạo CS1 `(markup_rate_bps=0, costing_revision=0)`; trước đó GET fallback 0 bps và không raise.

### 3.2 Endpoint

| Method | Path | Body | Trả |
| :-- | :-- | :-- | :-- |
| `GET` | `/api/v2/quotations/{id}/service-lines` | — | `{lines[], summary, revision}` |
| `POST` | `/api/v2/quotations/{id}/service-lines` | `{baseRevision, line}` | như trên |
| `PATCH` | `/api/v2/quotations/{id}/service-lines` | `{baseRevision, lines[{id, ...patch}]}` | như trên |
| `DELETE` | `/api/v2/quotations/{id}/service-lines/{lineId}` | `{baseRevision}` | như trên |
| `PATCH` | `/api/v2/quotations/{id}/costing-settings` | `{baseRevision, markupRatePercent}` | settings + lines + summary |

`PATCH` nhận **nhiều dòng một lần** ngay từ đầu — sprint 5 cần batch để debounce, thêm sau sẽ phải sửa contract.

Mọi endpoint: `_get_helpers()` function-scope → `require_owned_quotation` → `_get_db_session_factory()`.
`baseRevision` là **CS1.costing_revision**, không phải `QuotationDocument.revision` (vốn theo `(quotation_id, lang)`). Mọi mutation costing — settings, POST/PATCH/DELETE line, TripProfile recompute và apply pricing — CAS `costing_revision` trong cùng DB transaction; lệch ⇒ `409 REVISION_CONFLICT` + `recovery: "reload"` qua `main._v2_error_payload`.

### 3.3 `summary` — tính lúc đọc

```python
{
  "currency": "USD",
  "paxBillable": 6,
  "netTotalMinor": 787300,
  "sellTotalMinor": 984125,
  "perPersonMinor": 164021,
  "markupRateBps": 2000,
  "missingPriceCount": 3,
  "qtyFallbackCount": 2,
  "isCosted": true,                # sellTotalMinor > 0; chỉ là apply gate
  "coverage": {"status": "unknown", "missingCategories": []}
}
```

`markupRateBps` đọc từ CS1. API nhận/trả percent chỉ ở boundary và convert chính xác sang integer bps; core không nhận float. Tạo/update rate ngoài `[0, 9500]` ⇒ `422 VALIDATION_FAILED`. Missing CS1 của quotation legacy ⇒ 0 bps + `costingSettingsMissing: true`, không raise.

`currency` là invariant cứng: mọi `service_line.currency` phải bằng `CS1.currency`. POST/PATCH mismatch ⇒ `422 VALIDATION_FAILED`; không FX, không implicit conversion trong Phase 1.

### 3.4 Thứ tự trong service layer

```
load CS1 + lines (repo) → `price_lines` từ `qty` persisted → summary
```

`merge_params`/`resolve_qty` chỉ chạy khi draft, explicit recalculate hoặc staff yêu cầu recalc một line. Kết quả mới ghi atomically `params`, `params_source`, `qty`, `qty_fallback`, `formula_version`. `service_line_service.py` là nơi duy nhất chạm session. `core/rules/*` vẫn pure.

## 8. Forward-compat với Phase 2 (14.0) — không đổi scope sprint này

### 8.1 Sáu cột sẽ đến ở migration `_39`

Thiết kế sprint này phải **không giả định sự vắng mặt** của chúng. Tất cả nullable / có default ⇒ migration `_39` là thao tác thuần cộng, không backfill, không downtime.

```text
supplier_id · product_id · price_line_id      → FK catalog, TRUY VẾT
sell_override_minor                            → sale ghi đè giá bán một dòng
booking_status · confirmed_at · supplier_ref   → vòng đời ops
tariff_id                                      → ĐÃ CÓ; _39 chỉ gắn FK → rates.id
```

Hệ quả cụ thể cho code sprint này:

| Nơi | Ràng buộc |
| :-- | :-- |
| `routers/v2/schemas/service_line.py` | Response model dùng **explicit field list**, không `model_config = ConfigDict(from_attributes=True)` kiểu quét toàn bộ cột — thêm cột ở `_39` không được rò rỉ ra API chưa khai báo trong manifest |
| `service_line_service.py` | Hàm tính sell viết dạng `sell = line.sell_override_minor or apply_markup(net, bps)` **ngay từ bây giờ** (`sell_override_minor` chưa tồn tại ⇒ đọc qua `getattr(line, "sell_override_minor", None)`), để `_39` không phải sửa service layer |
| `price_source` | Vẫn 3 giá trị `catalog / manual / missing`. Phase 2 **không** thêm giá trị mới — `catalog` bao trùm mọi dòng join được rate |
| `currency` invariant | Phase 2 mở rộng: `rates.currency` cũng phải bằng `CS1.currency` khi capture. Sprint này chỉ cần giữ nguyên invariant line ↔ CS1 |

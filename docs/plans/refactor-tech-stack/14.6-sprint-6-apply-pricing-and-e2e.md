## 3. Tích hợp `pricing_facts` — điểm rủi ro cao nhất toàn dự án

### 3.1 Repo đã có tầng thương mại

`quote-generator/lib/rules/pricingReconciler.ts:49` có options (max 3) với `perAdultMinor`/`perChildMinor`/`groupTotalMinor`. Legacy gross-profit fields không là input của costing module.

`service_lines` là **giá vốn (net)**. `pricing_facts.options[]` là **giá bán**. Hai tầng khác nhau, không được lẫn.

### 3.2 Luồng áp giá

```
Σ service_lines.net_minor
   → apply_markup(net, CS1.markup_rate_bps)               # sprint 1
   → sell_total_minor
   → CanonicalPricingOption id = "opt-from-services"
   → pricingReconciler.inferOptionRatesFromTotal(sell_total, adults, children, childRatio)
   → perAdultMinor / perChildMinor
   → brochure hiển thị như hiện tại — KHÔNG đổi gì ở display layer
```

Tái dùng `inferOptionRatesFromTotal` đã có test. **Không viết lại phép chia perAdult/perChild.**

### 3.3 `markup_rate_bps` là SSoT duy nhất

```
sell = round_half_up(net * (10_000 + markup_rate_bps) / 10_000)
net = 1000, markup_rate_bps = 2000 → sell = 1200
```

`markup_rate_bps` là integer `[0, 9500]` của CS1, không per-line và không từ YAML live. Costing core chỉ tồn tại `apply_markup()`; contract test cấm GP-style formula.

### 3.4 Ba quy tắc ranh giới

1. **Áp giá là thao tác chủ động của sale**, không tự động. Quotation đã gửi khách không bị đổi giá vì ai đó sửa một dòng giá vốn.
2. Option `"opt-from-services"` do hệ thống quản lý. Hai option còn lại (max 3) sale tự nhập, module này **không đụng**.
3. `commission`, `contingency`, `paymentFee` **không** thuộc scope và không được implicit áp sau `sell_total`.
4. Nếu quotation đã published, mọi mutation costing phải tạo business successor; public release hiện có bất biến.
5. Managed option lưu `applied_costing_revision`, `applied_markup_rate_bps`, net/sell total và applied-at. Costing thay đổi sau apply ⇒ option `stale`, không tự cập nhật.

### 3.5 Endpoint

`POST /api/v2/quotations/{id}/service-lines:apply-pricing`

| Body | Trả |
| :-- | :-- |
| `{baseRevision, optionLabel?}` | `{pricingFacts, summary, revision}` |

Apply gate: `sell_total_minor > 0`. Bằng 0 ⇒ `422 VALIDATION_FAILED` + `fieldErrors[].path = "serviceLines"`. Publication có gate riêng: `sell_total_minor > 0` **và** coverage policy đạt; catalog rỗng với chỉ một giá thủ công không mặc định đủ publish.

### 6.1 Ba CI gate dạng lệnh — exit code ngắt CI

> **Lý do viết lại** — đo thật, không suy đoán:

| Lệnh cũ | Tình huống | Exit thực đo (bash) | Hệ quả |
| :-- | :-- | :-: | :-- |
| `grep -n '^import main' f.py` | file **sạch** | `1` | CI **đỏ oan** dưới `set -e` |
| `grep -n '^import main' f.py` | file **có vi phạm** | `0` | ❗ **lỗi lọt, CI xanh** |
| `git diff --stat -- <path đúng>` | **có** drift | `0` | ❗ **không chặn được** |
| `git diff --stat components/display/` | path không tồn tại ở root | `128` | Gate chưa từng kiểm cái gì |
| `git diff --quiet -- <path>` | **có** drift | `1` | ✅ dùng trực tiếp làm gate |

> Dòng thứ hai là lỗi nghiêm trọng nhất: `grep … # phải rỗng` **không bao giờ** chặn được vi phạm,
> vì đúng lúc vi phạm tồn tại thì `grep` báo thành công. Chỉ có người đọc output mới phát hiện ra —
> mà "người đọc output" không phải là một cổng.

```bash
#!/usr/bin/env bash
set -euo pipefail

# gate: no-main-import — router không được import main ở module level
if grep -Rn '^import main' routers/v2/services.py; then
  echo "FAIL[no-main-import]: dùng _get_helpers() function-scope thay cho module-level import"; exit 1
fi

# gate: display-drift — display layer phải bất động trong sprint này
#   git diff --quiet exit 1 khi CÓ khác biệt ⇒ dùng trực tiếp làm gate
if ! git diff --quiet "${CI_BASE_REF:-origin/main}"...HEAD -- quote-generator/components/display/; then
  echo "FAIL[display-drift]: sprint 6 không được chạm quote-generator/components/display/"
  git diff --stat "${CI_BASE_REF:-origin/main}"...HEAD -- quote-generator/components/display/
  exit 1
fi

# gate: single-markup — đúng một chỗ tính sell trong tầng service
count=$(grep -Rn --include='*.py' 'apply_markup(' services/ | grep -vc 'test' || true)
if [ "$count" -ne 1 ]; then
  echo "FAIL[single-markup]: tìm thấy $count chỗ gọi apply_markup( trong services/, mong đợi 1"; exit 1
fi
```
